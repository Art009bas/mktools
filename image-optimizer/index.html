ℹ️ Как это работает

  • Всё сжатие происходит в вашем браузере через Canvas API
  • Изображения не отправляются на сервер — безопасно
  • JPEG: регулировка качества (10–100%)
  • PNG: ресайз + конвертация в JPEG (если нет прозрачности)
  • Ресайз по максимальной ширине (пропорции сохраняются)
