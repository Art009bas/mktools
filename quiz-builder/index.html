Как использовать квиз-конструктор

Квизы — один из самых конверсионных форматов для сбора лидов. Люди охотнее отвечают на 4-5 вопросов, чем заполняют форму с 10 полями.

Сценарии: подбор тура по параметрам, калькулятор стоимости, тест на знание продукта, опрос для сегментации аудитории.

Готовый HTML-виджет можно вставить на любой сайт — работает без фреймворков. JSON подходит для загрузки в конструкторы (Tilda, Readymag) через Embed. JavaScript-формат — для React/Vue проектов.
