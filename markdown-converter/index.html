Markdown → HTML

  • Списки - 1.
  • Ссылки [text](url)
  • Изображения ![alt](url)
  • Таблицы | col | col |
  • Цитаты > text
  • Код ``` `code`
  • Чекбоксы - [x]

HTML → Markdown

  • Конвертирует обратно
  • Очищает лишние пробелы
  • Сохраняет структуру
  • Чистый Markdown без лишнего мусора

Markdown → Текст

  • Убирает всю разметку
  • Оставляет чистое содержание
  • Сохраняет абзацы
  • Убирает URL из ссылок
