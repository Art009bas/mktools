ℹ️ Форматы

JSON

  • Массив объектов: [{...},{...}]
  • Вложенные объекты раскрываются
  • Автоопределение ключей

CSV

  • Разделитель: , (запятая)
  • Первая строка — заголовки
  • Кавычки экранируются

XML

  • Структура: <item><key>val</key>
  • Массив объектов
  • Только одноимённые элементы

YAML

  • Отступы: 2 пробела
  • Массив: - ключ: значение
  • Объекты: ключ: значение

TXT

  • Формат: ключ: значение
  • Один объект на строку
  • Пустые строки — разделители
