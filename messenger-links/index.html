Ссылки мессенджеров — Telegram, WhatsApp

Генератор ссылок для Telegram и WhatsApp с предустановленным текстом и UTМ-метками.

Параметры Telegram-ссылки
Без @. Например: username или 79123456789
Параметр start
start — передаётся боту при старте. Используйте для трекинга кампаний.
Параметры WhatsApp-ссылки
В международном формате, без +. Пример: 79137588607

Готовая ссылка
